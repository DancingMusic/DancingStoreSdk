精选插件

频谱波形

经典频谱分析可视化，将音频频率数据转化为动态柱状波形，支持多种颜色映射模式。

by DancingTeam

粒子爆发

基于节拍检测的粒子发射系统，每次节拍触发绚丽的粒子爆发效果，支持自定义粒子形态。

by VisuaLab

几何旋转

Three.js 驱动的 3D 几何体场景，随音乐节奏旋转变换，呈现未来感十足的视觉效果。

by GeomX

星空隧道

穿越星空的隧道效果，低频驱动前进速度，高频控制星星密度，打造宇宙漫游般的沉浸感。

by CosmicDev

流体模拟

WebGL 流体动力学模拟，音频能量驱动流体的速度与色彩变化，营造梦幻般的视觉氛围。

by FlowStudio

声波涟漪

声音化为水面涟漪向外扩散，不同频段对应不同颜色的波纹，创造宁静而富有韵律的画面。

by WaveCraft

构建你的插件

使用 @musicdance/plugin-sdk 快速开发自定义可视化效果

my-plugin.ts 
import { DancePlugin, AudioData, RenderContext } from '@musicdance/plugin-sdk';

export class MyVisualizerPlugin implements DancePlugin {
  name = 'my-visualizer';
  version = '1.0.0';

  // Initialize canvas, WebGL context, etc.
  async init(ctx: RenderContext): Promise<void> {
    this.gl = ctx.canvas.getContext('webgl2');
    // Setup shaders, buffers...
  }

  // Called every frame with real-time audio data
  render(audio: AudioData, ctx: RenderContext): void {
    const { frequency, waveform, bpm, beat } = audio;
    // Your visualization logic here
  }

  // Cleanup resources
  dispose(): void {
    // Release GPU resources, cancel animations...
  }
}
